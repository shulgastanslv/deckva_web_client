# Анализ аудитории

## Кто продукт

**Deckva** (`deckva.by`) — веб-студия для **мультислайдовых каруселей** (Instagram и соседние форматы), с упором на чистый экспорт без логотипа студии. Позиционирование против «квадратных» редакторов вроде Canva: карусель как основной сценарий, а не побочный.

Гео и оплата: **Беларусь**, цена в **BYN**, эквайринг **bePaid**, контакты и самозанятость на лендинге — локальный B2C / микробизнес.

## Сегменты (по сигналам продукта и лендинга)

### 1. Основной: создатели контента и SMM

- Ведут Instagram / Threads / TikTok, регулярно делают посты из нескольких слайдов.
- Нужны шаблоны, быстрый экспорт, единый стиль.
- Боль: долго собирать карусель в универсальных редакторах или в Figma «с нуля».

**Ценность Pro:** безлимит проектов, папки по клиентам/кампаниям, чистый экспорт.

### 2. Фаундеры и соло-маркетологи

- Сами делают контент без дизайнера.
- Готовы платить небольшую фиксированную сумму (**~15 BYN**), если экономит часы.
- FAQ/копирайт целится в «команды, основателей, редакторов, маркетологов».

### 3. Небольшие агентства / фриланс

- Несколько клиентов → организации + папки.
- Инвайты завязаны на Pro владельца — модель «лид платит, команда заходит».
- Пока нет seat-биллинга: для агентства из 10 человек может быть тесно.

### 4. Не целевая (сейчас)

- Чистый мобайл-only пользователь — редактор **закрыт** на ширине &lt;768px.
- Enterprise / закупки по счёту юрлица без карты — нет.
- Тем, кому нужен AI «напиши карусель сам» — фичи нет.

## География и язык

| Сигнал | Вывод |
|--------|--------|
| Лендинг на русском | Коммуникация с RU/BY аудиторией |
| Студия / биллинг на английском | Продуктовый UI пока «dev-default»; для BY-аудитории лучше русифицировать ключевые экраны |
| `deckva.by`, BYN, bePaid | Ядро — Беларусь; экспорт в РФ/СНГ возможен, но оплата заточена под BY |
| Telegram + Threads в CTA | Органический рост через соцсети основателя |

## Jobs to be done

1. «Собрать карусель к посту сегодня вечером и выгрузить PNG/ZIP».
2. «Держать проекты клиентов отдельно (папки / орги)».
3. «Платить простой суммой с карты, без тарифов на места».

## Готовность платить

- Цена **15 BYN/мес** низкая для B2B, комфортная для соло.
- Нет триала → конверсия зависит от Free (3 карусели) как демо.
- Риск: если Free уже «достаточен», Pro берёт только папки/инвайты/безлимит — нужно явно продавать эти рычаги в UI.

## Гипотезы роста

1. Контент в Telegram/Threads с before/after каруселей → трафик на `/studio`.
2. Шаблоны под ниши (e-com, курсы, личный бренд) → быстрее time-to-value.
3. Русификация студии → меньше трения для основной аудитории.
4. Позже: лёгкий мобайл preview / комментарии, не полный редактор.

## Антиперсоны

- Пользователь, которому нужен только один квадратный пост раз в месяц → Canva / сторис-редактор дешевле по вниманию.
- Команда, которой нужен совместный realtime-редактор как Figma → не наш сценарий.
- Кто ищет генеративный AI-контент end-to-end → пока мимо.

## Краткий вывод

Ядро аудитории — **русскоязычные создатели и маркетологи в Беларуси**, которым карусель — рабочий формат, а не эксперимент. Продукт уже закрывает create/edit/export; монетизация и локальный биллинг совпадают с гео. Главные продуктовые разрывы с аудиторией: **язык UI**, **мобайл**, и ясная демонстрация, зачем Free-пользователю апгрейд после третьей карусели.
