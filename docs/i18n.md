# i18n — English / Russian / Belarusian

## Model

- Library: **next-intl** (App Router, **no URL locale prefix**)
- Locales: `en`, `ru`, `be` (default **`ru`**)
- Preference cookie: `NEXT_LOCALE`
- If cookie missing, `proxy.ts` negotiates `Accept-Language` and sets the cookie

UI language is independent of carousel *content* language (`inferPromptLanguage`).

## Layout

```
messages/{en,ru,be}.json
i18n/request.ts              # locale + catalog for RSC / actions
lib/i18n/config.ts           # locales, labels, negotiation
lib/i18n/set-locale.ts       # server action: set cookie + revalidate
components/i18n/locale-switcher.tsx
lib/messages.ts              # await getMessages() for Server Actions
```

## Switcher

Header on landing + studio. Calls `setAppLocale` → cookie → `router.refresh()`.

## Catalogs

Namespaces in JSON:

- `common` — language names, sign in/out, shared chrome
- `meta` — document title / OG
- `landing` — nav / CTAs / legal (body copy still migrating)
- `studio` — create pipeline chrome
- `errors` / `notifications` — former `lib/messages.ts`

Server Actions: `const messages = await getMessages()` then `messages.errors.*`.
