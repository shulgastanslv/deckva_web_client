# Фичи: что есть и что нужно для базового MVP

Базовый MVP Deckva: человек из Беларуси/СНГ может **зарегистрироваться → сделать карусель → экспортировать → при желании оплатить Pro картой**.

## Нужно закрыть для «базового» продакшен-MVP

Приоритет сверху вниз.

### Must-have

1. **Боевой bePaid** — ключи в env, тест реальной карты, проверка продления и отмены.
2. **Стабильный деплой** — прод Next + Postgres + `DECKVA_TOOLS_URL` не на localhost.
3. **SMTP на проде** — иначе verify/reset ломают онбординг.
4. **Согласованность цены и оффера** — везде 15 BYN/мес (убрать остатки «разовый $15» в FAQ/копирайте, если ещё есть).
5. **Жёсткий gate экспорта** — если «без водяного знака» = Pro, это должно реально работать в коде экспорта (сейчас маркетинг сильнее enforcement).
6. **Минимальная аналитика** — хотя бы события: регистрация, первая карусель, upgrade, churn (PostHog / Plausible / аналог). Без этого нельзя проверить MVP.

### Should-have (сразу после запуска)

7. Webhook / cron продления подписки (сейчас только lazy-renew).
8. Онбординг: 1–2 шага «создай первую карусель из шаблона».
9. Чек / письмо после успешной оплаты.
10. Лимиты Iconscout на Free, чтобы не сжечь credits.
11. Мониторинг ошибок (Sentry или аналог).

### Можно отложить (не блокер MVP)

- Полноценный мобильный редактор
- Brand kits как сущность
- Реферальная программа (в UI есть зачатки copy)
- AI-генерация контента
- Org seats / корпоративные счета
- Мультиязычность студии (сейчас лендинг RU, UI студии в основном EN)

## Критерий «MVP запущен»

- [ ] Новый пользователь проходит путь до экспорта без ручной помощи
- [ ] Pro списывает **реальные** 15 BYN и отображается в Billing
- [ ] Отмена сохраняет доступ до конца периода
- [ ] Free упирается в 3 карусели и видит upgrade
- [ ] Есть хотя бы одна метрика конверсии в Pro
