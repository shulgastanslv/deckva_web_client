# Расходы на сервис (BYN / USD)

Оценка **на текущий момент** по коду и типичным тарифам вендоров. Точные цифры зависят от вашего тарифа и трафика; ниже — ориентир для юнит-экономики при цене продукта **15 BYN/мес ≈ 4,5–5 USD** (курс ~3,0–3,3 BYN за 1 USD; пересчитывайте по НБРБ).

## Сводка

| Статья | Зачем | Ориентир в месяц | Примечание |
|--------|--------|------------------|------------|
| Хостинг Next.js (Vercel / аналог) | сайт + API | **0–25 USD** (~0–80 BYN) | Hobby бесплатно; Pro ~20 USD |
| PostgreSQL (Supabase / Prisma Postgres) | данные | **0–25 USD** (~0–80 BYN) | free tier часто хватает на MVP |
| bePaid | эквайринг карт BYN | **комиссия с оборота** | обычно ~2–3,5% + фикс за успешный платёж; уточнять в договоре |
| Iconscout | иконки / SVG в редакторе | **0–50+ USD** (~0–165 BYN) | квоты и credits; в коде есть ошибки `quota_exhausted` |
| SMTP (почта) | подтверждение email, сброс пароля | **0–15 USD** (~0–50 BYN) | Resend / SendGrid / свой SMTP |
| deckva-tools (remove-bg, upscale, magic-layer) | GPU/CPU-сервис | **0–50+ USD** (~0–165 BYN) | отдельный хост (`DECKVA_TOOLS_URL`); на localhost — 0 |
| Домен deckva.by | бренд | **~10–20 USD/год** (~3 BYN/мес) | раз в год |
| Google OAuth / Fonts | вход, шрифты | **0** | в рамках бесплатных квот |
| AI (OpenAI и т.п.) | — | **0** | в проекте **нет** |

**Грубый floor без трафика (MVP, free-тиры):** ≈ **0–30 USD/мес** (~0–100 BYN), плюс комиссия bePaid с реальных оплат.

**При живом трафике и платных квотах Iconscout + отдельный tools-сервер:** легко **50–150 USD/мес** (~150–500 BYN) до масштабирования.

## Детали по статьям

### Выручка продукта

- Подписка Pro: **15 BYN / пользователь / месяц**.
- При курсе 3,2 BYN/USD → **~4,7 USD** с одного платящего.
- После комиссии bePaid (~3%) остаётся порядка **~14,5 BYN (~4,5 USD)** — до вычета хостинга и API.

### bePaid

- Не фикс «за месяц», а **% от успешных списаний** (+ возможный фикс).
- Тестовый режим: `BEPAID_TEST=true`.
- Без ключей — sandbox, реальных расходов на эквайринг нет.

### Iconscout

- Env: `ICONSCOUT_CLIENT_ID`, `ICONSCOUT_API_KEY`.
- Расход растёт с поиском и скачиванием SVG; юр. текст в продукте предупреждает про credits аккаунта.
- Имеет смысл кэшировать популярные ассеты и лимитировать free-пользователей.

### deckva-tools

- Прокси: `lib/image/tools-proxy.ts` → `DECKVA_TOOLS_URL` (по умолчанию `127.0.0.1:8000`).
- На проде это отдельный инстанс (CPU/GPU). Пока крутится локально — **0** в opex.

### База и хостинг

- `DATABASE_URL` → PostgreSQL (часто Supabase pooler).
- Next 16; деплой в репозитории явно не зафиксирован (типично Vercel).
